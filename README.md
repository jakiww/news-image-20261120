The program copies `entry.png` to `/output/entry.png`.

## The six stories

1. **Markets — Asia's markets plunge.** The Nikkei falls 4.5%, the Kospi 4.8%
   and Taiwan 6% in an AI-chip selloff; SoftBank drops 14% after Anthropic's
   Nasdaq debut.
2. **Climate — COP31 ends in deadlock.** On the final day in Antalya the
   slimmed draft drops every fossil-fuel mention and no deal is reached as
   talks run past midnight.
3. **Australia — Sydney terror raids.** Police arrest three in dawn raids; a
   man, 35, is charged over an alleged vehicle-bomb document and extremist
   material.
4. **Science — Cancer pill brings hope.** Daraxonrasib plus chemo shrank or
   cleared tumours in 6 in 10 pancreatic-cancer patients in a 61-person
   trial; doctors stress it is not a cure yet.
5. **Cyber — UK fridges taken offline.** Tens of thousands of supermarket
   fridges are secured in a secret operation after a flaw is found in their
   temperature controllers.
6. **Gaming — GTA VI tops $2bn in a day.** Sensor Tower counts 24.6 million
   copies and $2.36 billion on day one, the biggest game launch ever;
   Take-Two has not confirmed the figures.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program needs no network and no dependencies: it copies the image the
repository holds. The image is a 1024 by 1024 PNG, drawn for this entry,
with each of the six stories named in its own panel so the day can be read
from the picture alone.
